# Python Assignment 1: Data Structures – Strings & Tuples

## 📌 Description
This assignment focuses on Python Data Structures, specifically Strings and Tuples. It includes practical exercises to understand string manipulation and tuple operations using Python.

## 📚 Topics Covered

### 1. Strings
- String creation and indexing
- Finding string length
- Uppercase and lowercase conversion
- String slicing and reversing
- Counting characters
- Replacing words
- Checking string prefixes
- Removing extra spaces

### 2. Tuples
- Creating and accessing tuples
- Tuple indexing
- Finding tuple length
- Maximum and minimum values
- Calculating the sum
- Counting elements
- Finding element indexes
- Converting tuples into lists

## 🛠️ Tools Used
- Python
- Jupyter Notebook / VS Code

## 🎯 Learning Outcomes
- Understanding Python Strings and Tuples.
- Practising built-in Python functions.
- Improving logical thinking and problem-solving skills.
- Building a strong foundation for Data Analytics.
